# HomeworkPlan

How much homework per grade? Get nightly minutes by the 10-minute rule, then build a schedule with breaks and timers. Free tool.

## Features
- Nightly homework minutes by grade using the 10-minute rule
- Schedule builder that splits time across subjects with breaks
- Break countdown timer plus weekend catch-up mode
